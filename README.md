# 政見座標

> 用 16 道台灣公共議題，找出你的四軸政治價值、討論系人格與思想鄰居。

[立即開始測驗](https://atlasforcn.github.io/political-mbti/) · [閱讀完整方法](METHODOLOGY.md) · [查看題目審查](QUESTION_REVIEW.md)

「政見座標」不是要把人塞進單一的左派／右派標籤，而是把政治判斷拆成四組可能彼此拉扯的價值選擇：政府應該承擔多少風險、分配時重視結果或程序、改革應該多快，以及我們如何理解個人與結構的責任。

網站不需要登入，也沒有後端。作答、計分、比較與分享全部在瀏覽器內完成。

## 你會得到什麼？

- **四軸政治座標**：保留 0–100 的連續分數，不只顯示四個字母。
- **臺灣現況提示**：每個議題先提供有日期的制度背景與官方來源，再請玩家判斷政策取捨。
- **16 型價值摘要**：用容易記憶的代碼與名稱整理整體方向。
- **討論系人格**：包含立場音量、最不像自己的一票，以及可以丟給朋友的開戰題。
- **思想鄰居**：每型提供一位哲學家或社會學家、一個核心問題與一本代表作，再連到中文入門文章搜尋。
- **政府邊界剖面**：分開比較社會保障與經濟治理，保留「社會議題支持政府、經濟議題偏好市場」等交叉立場。
- **多人接力討論桌**：同一條網址最多加入 6 人，並排查看逐題答案、四軸跨度與最大分歧題。

思想鄰居是一個延伸閱讀入口，不代表玩家等同該思想家，也不表示思想家會同意玩家的所有答案。

## 四條測量軸線

| 軸線 | 一端 | 另一端 | 核心問題 |
| --- | --- | --- | --- |
| 公共角色 | 公共保障（S） | 市場自治（L） | 共同風險應由政府承擔，還是保留市場與個人選擇？ |
| 分配原則 | 結果平等（E） | 程序公平（F） | 應主動縮小結果差距，還是優先維持一致、公開的規則？ |
| 改革步調 | 積極改革（A） | 穩健漸進（T） | 面對制度問題應快速重設，還是先試辦、累積共識？ |
| 責任歸因 | 個人能動（R） | 結構脈絡（C） | 社會成果較應歸因於個人選擇，還是制度、環境與起點？ |

四個字母只是摘要。真正的結果仍是四條連續座標；接近中線時，不應把字母解讀成強烈立場。

## 題庫與作答方式

4.0 題庫共有 64 題，分布在 4 條軸線與 16 個議題。每個議題有 4 題，正、反向敘述各 2 題。題目改以全民健保、最低工資、社會住宅、托育、碳費、長照 3.0、AI 治理等臺灣現行制度呈現，作答畫面會先顯示簡短背景、資料時間與官方來源。

每次測驗會：

1. 從每個議題抽出 1 題，共 16 題。
2. 維持每條軸線正、反向題平衡。
3. 提供四級方向選項，以及不參與計分的「不確定」。
4. 完成後將各軸換算為 0–100 分，50 為中線。

背景資料只協助理解政策現況，不參與計分，也不代表官方機關支持題目的任何一端。當題目意義有實質變更，題庫會升級版本；舊版分享紀錄不會套用到新題目，以免同一題號被錯誤解讀。

詳細計分、資料來源與後續驗證規格請見 [METHODOLOGY.md](METHODOLOGY.md)。

## 多人分享如何運作？

完成測驗後，暱稱、題號與答案會編碼在網址的 `#r=` hash 中。朋友開啟網址後可以：

1. 查看目前所有人的結果。
2. 點擊「加入我的答案」。
3. 完成自己的 16 題。
4. 把包含全員紀錄的新網址分享給下一位。

同一條網址最多保存 6 人。不同玩家可能抽到不同題目；結果表只比較實際出現的題目，未抽到會明確標示，不會被當成中立或反對。

### 隱私提醒

- hash 不會隨一般 HTTP 請求傳送給 GitHub Pages。
- 作答資料不會上傳到本站伺服器。
- 未完成進度只保存在瀏覽器的 `localStorage`。
- 網址內容是**編碼，不是加密**。任何取得完整網址的人，都能在本站還原其中的暱稱與答案。

請把分享網址視為可讀資料，不要使用真實姓名或敏感身分資訊作為暱稱。

## 在本機執行

需求：Node.js 18 以上與 Python 3。

```bash
git clone https://github.com/atlasforcn/political-mbti.git
cd political-mbti
npm test
npm run serve
```

接著開啟 <http://localhost:4173>。

這是一個不需要打包的靜態網站；執行時沒有第三方 JavaScript 相依套件。

## 自動測試

```bash
npm test
```

測試涵蓋：

- 題庫議題、方向與抽題平衡。
- 四軸計分、中線、不確定答案與邊界條件。
- 測驗續作與題組還原。
- 單人及多人 hash 編解碼。
- 暱稱、人數與損壞網址驗證。
- 16 型思想鄰居資料完整性。
- 討論系人格、立場音量與反差答案。

## 設計靈感

- [SBTI](https://sbti.dev/)：啟發了「結果要能成為一句有記憶點的自我介紹」與娛樂化分享的呈現方式；本站沒有複製其題目、角色或類型系統。
- [gnehs/travel-questions](https://github.com/gnehs/travel-questions)：啟發了具名答案、同一網址累積多人結果，以及讓下一位加入的接力分享流程。

## 重要限制

這是一個**待驗證的政治價值探索工具**，不是：

- Myers–Briggs Type Indicator（MBTI）或心理診斷。
- 政黨、候選人或投票建議器。
- 已以台灣代表性樣本建立常模的正式量表。
- 對思想家立場的完整分類或學術背書。

目前尚未完成人類專家 Delphi、受測者認知訪談、代表性樣本的信度與效度分析，以及跨群體測量恆等性檢查。結果適合用來整理問題、交換觀點與展開閱讀，不適合用來替自己或別人下政治定論。
